
 # linux_practice

My practice repository for learning Linux, terminal commands, and basic shell scripting.

## What's in here

- *basic-commands/*: Notes and cheat sheets for common terminal commands (navigation, file permissions, searching).
- *scripts/*: Simple Bash scripts for practicing loops, conditionals, and system automation.
- *notes/*: Quick reference notes on Linux concepts and administration.

## System Setup

- *OS:* Ubuntu (via VirtualBox) / Linux Terminal
- *Shell:* Bash

## How to run scripts

Make sure to give executable permissions before running any script:

```bash
chmod +x scripts/filename.sh
./scripts/filename.sh
